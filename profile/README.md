# ZL Audio

ZL Audio makes audio plugins and audio processing tools.

Plugins:

- [ZLEqualizer](https://github.com/ZL-Audio/ZLEqualizer): dynamic equalizer plugin
- [ZLCompressor](https://github.com/ZL-Audio/ZLCompressor): dynamic range processor plugin
- [ZLSplitter](https://github.com/ZL-Audio/ZLSplitter): splitter plugin

DSP:

- [zldsp::fft](https://github.com/ZL-Audio/zldsp_fft): high-performance FFT library (used in ZL Audio plugins)


Tools:

- [midi-pitch](https://github.com/ZL-Audio/midi-pitch): compare MIDI with vocal pitch
